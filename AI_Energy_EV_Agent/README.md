# AI Energy & EV Fleet Optimization Agent

Starter project for analyzing a simulated EV fleet.

## Run

1. Open this folder in VS Code.
2. Open Terminal.
3. Install requirements:

   pip install -r requirements.txt

4. Run:

   python main.py

Current stage:
- Simulated EV fleet data
- Battery Agent
- Battery charging priority rules

Next stages:
